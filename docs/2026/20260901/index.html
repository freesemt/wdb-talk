■ 関連知識＋作業状況

    ・  AI（LLM）を供給する主な企業（一般常識レベル、企業規模の目安つき）

        ※ 規模は「上場か否か」と大まかなオーダー感による目安。正確な時価総額・評価額は
          日々変動し検証もできないため、あくまで会話用の目安として使う。

        【超大企業・上場（時価総額が世界最大級）】
            - Microsoft … Copilot等（OpenAIのモデル＋自社モデル）
            - Google（Alphabet/DeepMind）… Gemini
            - Amazon … Titan / Nova（自社モデル）＋Anthropicへの出資
            - Meta … Llama（重み公開モデル）

        【大型・非上場（評価額が数百億〜千億ドル級とされるAI専業）】
            - OpenAI … GPT / ChatGPT（Microsoftが大規模出資・提携）
            - Anthropic … Claude（Amazon・Googleが出資）
            - xAI（Elon Musk）… Grok

        【中堅・非上場（評価額は数十億ドル級）】
            - Mistral AI（フランス）… 重み公開モデル中心
            - Cohere（カナダ、企業向け特化）

        【大企業・上場（中国）】
            - Alibaba … Qwen
            - Baidu … ERNIE

        【非公開・評価額不明だが技術的影響力が大きい（中国）】
            - DeepSeek
            - Zhipu AI … GLM

        【大企業・上場（日本）】
            - NTT … tsuzumi（自社LLM）
            - SoftBank Group … OpenAI等への出資、SB Intuitionsで自社LLM開発
            - LY Corporation（LINEヤフー）… HyperCLOVA X 等
            - 楽天グループ … Rakuten AI
            - NEC / 富士通 … 企業向け生成AI

        【非上場スタートアップ（日本）】
            - Sakana AI … 進化的モデル統合手法（元Google/OpenAI研究者が創業）
            - Preferred Networks (PFN) … PLaMoシリーズ
            - ELYZA（東京大学発）… 日本語LLMのチューニング
            - Turing … 自動運転＋LLM

        【産学官連携（日本）】
            - Fugaku-LLM … 理研・東工大・富士通等が連携、スパコン「富岳」を活用

        ※ 日本勢は、投資規模・モデル規模とも米中の最大手と比べるとかなり小さいのが実情。
          経済産業省のGENIACプログラム等、国が開発費を補助する枠組みも動いている。

        ※ 本リポジトリではこの会話自体も GitHub Copilot（OpenAI/Anthropic等のモデルを利用）で支援されている。
